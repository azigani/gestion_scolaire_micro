# EduManager Frontend

Angular frontend application for the EduManager School Management System.

## Prerequisites

- Node.js 18+ 
- npm 9+

## Installation

```bash
npm install
```

## Development

```bash
npm start
```

The application will be available at `http://localhost:4200`

## Build

```bash
npm run build
```

## Features

- Multi-tenant support
- JWT authentication
- Material Design UI
- Lazy-loaded feature modules
- Internationalization support
- Responsive design

## Architecture

- **Core Services**: API service, Auth service, Interceptors
- **Feature Modules**: Dashboard, Students, Classes, Academic, Financial, HR, Communication, Settings
- **Shared Components**: Material Design components
